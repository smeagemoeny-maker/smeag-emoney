💳 PUSAN MART 카드 리더기 설치

Mart · Office · Cafe 화면에서 USB 카드 리더기(ACR122U)로 학생 카드를 읽게 해주는 작은 프로그램입니다.

PC 한 대당 한 번만 설치 · 이후 로그인할 때마다 자동 실행
이 PC 상태 확인 중…

📋 무엇을, 왜 설치하나요?

  • USB 카드 리더기(ACR122U)를 PC에서 쓰려면 이 작은 연결 프로그램이 필요합니다.
  • 브라우저만으로는 USB 리더기를 직접 잡을 수 없어서(보안), 이 프로그램이 리더기와 화면을 이어줍니다.
  • PC 한 대당 한 번만 설치하면 됩니다. 이후 로그인할 때마다 자동으로 켜지고, 꺼지면 다시 켜집니다.
📱 핸드폰·태블릿은 설치가 필요 없습니다. Android 기기는 카드를 댈 때 “NFC 사용 허용” 한 번만 수락하면 바로 됩니다. 설치가 필요한 건 PC + USB 리더기뿐입니다.

위쪽 탭에서 사용하는 기기(Windows / Mac)를 고르세요.

🪟 방법 A 가장 확실함 · 추천

긴 명령을 붙여넣지 않고, 열려 있는 PowerShell 창에 한 줄만 붙여넣는 방법입니다.

  1. 시작 메뉴에서 PowerShell 검색 → 마우스 오른쪽 → 관리자 권한으로 실행.
  2. 아래 복사를 누르고, 열린 창에 마우스 오른쪽 클릭(붙여넣기) 후 Enter.
[Net.ServicePointManager]::SecurityProtocol='Tls12';$b='https://smeag-estore.vercel.app/bridge';irm $b/install.ps1|iex
“관리자 권한으로 실행”이 다른 계정 로그인을 요구하거나 같은 오류가 나면 → 문제 해결 탭을 보세요. 그 PC는 관리자만 풀 수 있습니다.

🪟 방법 B 설치 파일 받기

파일을 받아 더블클릭하는 방법입니다. 일부 PC는 브라우저·백신이 .cmd 받기를 막습니다. 그럴 땐 ZIP으로 받으세요.

  1. 아래 버튼으로 설치 파일을 받습니다. (막히면 ZIP → 압축 풀기)
  2. 받은 install.cmd 를 더블클릭합니다.
  3. Windows 경고가 뜨면 추가 정보 → 실행 을 누릅니다.
⬇ ZIP으로 받기 (권장) install.cmd 직접 받기 제거 파일

🪟 방법 C Win+R 한 줄

  1. 키보드에서 Win 키 + R
  2. 아래 줄을 붙여넣고 Enter
powershell -NoProfile -ExecutionPolicy Bypass -c "[Net.ServicePointManager]::SecurityProtocol='Tls12';$b='https://smeag-estore.vercel.app/bridge';irm $b/install.ps1|iex"

제거: Win+R 에 아래를 붙여넣기 →

powershell -NoProfile -ExecutionPolicy Bypass -c "irm https://smeag-estore.vercel.app/bridge/uninstall.ps1|iex"
“액세스할 수 없습니다” 오류가 나면 Win+R이 막힌 것입니다. 방법 A(관리자 PowerShell)를 쓰세요.

🍎 macOS 설치

  1. 터미널 앱을 엽니다 (Cmd + Space → “터미널”).
  2. 아래 줄을 붙여넣고 Return.
curl -fsSL https://smeag-estore.vercel.app/bridge/install.sh | sh

제거:

curl -fsSL https://smeag-estore.vercel.app/bridge/install.sh | sh -s -- --remove

🔌 리더기 연결 · 동작 확인

  1. USB 카드 리더기를 PC에 직접 꽂습니다. (허브 말고 본체에)
  2. 리더기에 불이 들어오면 Mart / Office 화면을 새로고침 합니다.
  3. 화면 위쪽에 ● Card reader connected 가 보이면 정상입니다.
  4. 카드를 리더기에 대면 학생이 조회됩니다.

이 페이지를 새로고침했을 때 맨 위 상태가 “설정 완료” 로 바뀌어도 확인됩니다.

⚠ 문제 해결

① “이 장치, 경로 또는 파일에 액세스할 수 없습니다” 오류

그 PC에서 PowerShell 실행이 막혀 있는 것입니다. 다음 순서로 확인하세요.

시작 메뉴에서 PowerShell 검색 → 마우스 오른쪽 → 관리자 권한으로 실행
· 바로 열림 → 그 창에 Windows 탭 방법 B의 한 줄을 붙여넣고 Enter. 설치됩니다.
· 다른 계정 로그인 요구 → 평소 쓰는 계정은 일반 사용자입니다. 관리자에게 그 계정 기준 설치를 요청하세요.
· 똑같은 오류 → 관리자가 정책/백신으로 PowerShell을 막은 PC입니다. 그 PC 관리자만 풀 수 있습니다.
② 설치는 됐는데 카드가 안 읽힌다

리더기가 빠졌거나 연결이 헐거운 경우가 대부분입니다. USB를 다시 꽂고(허브 말고 본체에) 화면을 새로고침하세요. 리더기 불이 들어오는지 먼저 확인합니다.

③ 카드가 두 번 입력된다

예전 키보드 방식 프로그램이 함께 떠 있는 경우입니다. 관리자에게 문의하세요.

웹페이지가 클릭 없이 PC에 프로그램을 자동으로 까는 것은 보안상 불가능합니다. 파일을 받아 여는 과정은 생략할 수 없습니다.
