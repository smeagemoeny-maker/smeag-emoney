💳 PUSAN MART Card Reader Setup

A small program that lets the Mart, Office and Cafe screens read student cards with a USB card reader (ACR122U).

Install once per PC · starts automatically at every login
Checking this PC…

📋 What is this and why install it?

  • To use the USB card reader (ACR122U) on a PC, you need this small connector program.
  • A browser cannot talk to a USB reader directly (security), so this program connects the reader to the screen.
  • Install it once per PC. After that it starts at every login and restarts if it stops.
📱 Phones and tablets need no install. On Android, just accept “Allow NFC” once when tapping a card. Only a PC + USB reader needs this install.

Choose your device (Windows / Mac) in the tabs above.

🪟 Method A Most reliable · Recommended

Paste just one line into an open PowerShell window.

  1. Search PowerShell in the Start menu → right-click → Run as administrator.
  2. Press Copy below, right-click (paste) in the open window, then press Enter.
[Net.ServicePointManager]::SecurityProtocol='Tls12';$b='https://smeag-estore.vercel.app/bridge';irm $b/install.ps1|iex
If “Run as administrator” asks for another account, or you get the same error → see the Troubleshooting tab. Only that PC's administrator can unblock it.

🪟 Method B Download installer

Download a file and double-click it. On some PCs the browser or antivirus blocks .cmd downloads. If so, download the ZIP.

  1. Download the installer with the button below. (If blocked: ZIP → extract)
  2. Double-click the downloaded install.cmd.
  3. If Windows shows a warning, press More info → Run anyway.
⬇ Download ZIP (recommended) Download install.cmd Uninstaller

🪟 Method C One line in Win+R

  1. Press Win key + R
  2. Paste the line below and press Enter
powershell -NoProfile -ExecutionPolicy Bypass -c "[Net.ServicePointManager]::SecurityProtocol='Tls12';$b='https://smeag-estore.vercel.app/bridge';irm $b/install.ps1|iex"

Uninstall: paste this into Win+R →

powershell -NoProfile -ExecutionPolicy Bypass -c "irm https://smeag-estore.vercel.app/bridge/uninstall.ps1|iex"
If you get a “cannot access” error, Win+R is blocked. Use Method A (administrator PowerShell).

🍎 macOS Setup

  1. Open the Terminal app (Cmd + Space → “Terminal”).
  2. Paste the line below and press Return.
curl -fsSL https://smeag-estore.vercel.app/bridge/install.sh | sh

Uninstall:

curl -fsSL https://smeag-estore.vercel.app/bridge/install.sh | sh -s -- --remove

🔌 Connect the reader · Check it works

  1. Plug the USB card reader directly into the PC (not into a hub).
  2. When the reader light turns on, reload the Mart / Office screen.
  3. ● Card reader connected at the top of the screen means it is working.
  4. Tap a card on the reader to look up the student.

You can also reload this page: the status at the top changes to “Setup complete”.

⚠ Troubleshooting

① “Windows cannot access the specified device, path, or file” error

PowerShell is blocked on that PC. Check in this order:

Search PowerShell in the Start menu → right-click → Run as administrator
· Opens right away → paste the one line from Method A on the Windows tab and press Enter. It installs.
· Asks for another account → your usual account is a standard user. Ask the administrator to install it for that account.
· Same error → the administrator blocked PowerShell by policy or antivirus. Only that PC's administrator can unblock it.
② Installed, but cards are not read

Usually the reader is unplugged or loose. Plug the USB back in (into the PC, not a hub) and reload the screen. First check that the reader light is on.

③ A card is entered twice

The old keyboard-mode program is also running. Ask the administrator.

For security, a web page cannot install a program on a PC without a click. Downloading and opening the file cannot be skipped.
